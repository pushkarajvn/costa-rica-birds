Costa Rica Birds — Tour Offline Update

Purpose:
- Keeps the app shell available with no internet.
- Keeps your existing 944-species AOCR checklist cache.
- Keeps Seen marks, language choice, and existing photo URL cache keys unchanged.
- Adds a visible offline-readiness message.

IMPORTANT BEFORE THE TOUR
1. Upload all files to the ROOT of the same GitHub Pages repository.
2. Open the app on the SAME iPhone while you still have internet.
3. Wait until the app says:
   “✓ 944-bird checklist saved for offline use”
4. Put the iPhone in Airplane Mode.
5. Close the app completely, reopen it from the Home Screen, search for several birds,
   and mark/unmark one test bird.
6. Turn Airplane Mode off and restore the test mark if desired.

The checklist and Seen tracking will work offline once the 944 list is saved.
Bird photos are NOT guaranteed offline unless that particular image has already been
stored by the browser; the checklist itself does not depend on the photos.

Do not clear Safari website data before or during the trip.
