# Costa Rica Birds

iPhone-friendly bird checklist for GitHub Pages.

## Publish
1. Upload `index.html`, `manifest.webmanifest`, and `sw.js` to the repository root.
2. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
3. Select `main` and `/ (root)`, then Save.
4. Open the Pages URL in Safari.
5. Share → Add to Home Screen.

On first online launch the app attempts to synchronize the AOCR official online checklist and cache it locally. Seen marks are stored on the device.
